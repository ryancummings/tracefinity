# Keyboard Shortcuts

| Shortcut | Action | Context |
|-|-|-|
| Ctrl/Cmd+Z | Undo | Tool editor, bin editor |
| Ctrl/Cmd+Shift+Z | Redo | Tool editor, bin editor |
| Delete | Use the selected item's Delete or Remove action | Tool outlines, bin layout, drawer plan |
| Delete | Activate a focused Delete or Remove button | Library and project lists, confirmation dialogs |
| Escape | Cancel edit / close modal | Modals, inline edits, search, labels |
| Enter | Confirm text input | Labels, rename fields, numeric inputs |
| Space (hold) | Pan canvas | Tool editor |
| Scroll wheel | Zoom | Tool editor |
